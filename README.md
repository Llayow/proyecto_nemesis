# 🔐 Proyecto Némesis — Escape Room Cognitivo con IA

Juego de escape room cognitivo multijugador para aula, diseñado para **30 participantes en 6 equipos**.

## 🎮 Jugar ahora
👉 **[https://TU-USUARIO.github.io/proyecto-nemesis](https://TU-USUARIO.github.io/proyecto-nemesis)**

---

## ¿Qué es?

Un juego educativo en el que los equipos resuelven acertijos cognitivos para desencriptar un código maestro. Incluye:

- **Ronda 1** — Cifrado de César (análisis lógico)
- **Ronda 2** — Secuencia matemática rota (razonamiento abstracto)
- **Ronda 3** — Mapa de Alianzas (negociación grupal entre equipos)
- **Ronda 4** — Dilema del Prisionero (cooperar vs. desertar)
- 🧠 Pistas de IA (Claude Sonnet) integradas
- Tablero de puntuaciones en tiempo real
- Salas con código de acceso para el instructor

## 🚀 Cómo usar

1. El **instructor** crea una sala y obtiene un código
2. Los **agentes** ingresan el código para unirse
3. El instructor controla el avance de rondas desde su panel
4. Al final, se revelan resultados y se hace el debrief pedagógico

## 🛠️ Tecnología

- HTML + CSS + JavaScript (archivo único, sin dependencias)
- Almacenamiento compartido vía `window.storage` (Claude Artifacts)
- IA integrada vía Anthropic API (Claude Sonnet)

## 📋 Requisitos

- Navegador moderno (Chrome, Firefox, Edge)
- Conexión a internet (para pistas de IA)
- ~30 participantes con dispositivo propio
